# FDE Training Lab

一个通过 **真实业务模拟 → 完整方案确认 → 固定标准评分 → 深度复盘 → 定向训练** 持续提升 Forward Deployed Engineer 能力的训练仓库。

## 当前目标

当前阶段不追求系统学习大量产品、咨询、项目管理理论，而是：

- 技术能力继续作为主线；
- FDE 非技术能力通过真实工作 + 模拟训练逐步形成肌肉记忆；
- 用固定评分体系观察能力变化；
- 把高价值经验沉淀为个人 FDE Playbook。

## 训练闭环

1. Load Current Profile
2. Select Training Focus
3. Generate Scenario
4. Role-play Simulation
5. Final Proposal
6. Full Review
7. Score
8. Compare With History
9. Extract Lessons
10. Update Current Profile
11. Commit to GitHub

## 核心目录

- `playbook/`：工作前快速阅读的行动原则
- `framework/`：能力模型、评分标准、模拟协议
- `simulations/`：每次完整模拟的案例档案
- `progress/`：当前能力画像与历史变化
- `prompts/`：ChatGPT Project / Work 使用的固定指令
- `templates/`：新案例和复盘模板
